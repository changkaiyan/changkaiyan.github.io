2025

  1. MICRO
    Kaiyan Chang, Wenlong Zhu, Shengwen Liang, and 2 more authors
    In Proceedings of the IEEE/ACM International Symposium on Microarchitecture, 2025
    DOI Bib 1

    LLMulator is a progressive numeric modeling framework for fast, generalizable performance prediction on dataflow accelerators. It uses LLM program semantics, categorical token modeling for numeric values, reinforcement-learning-based dynamic calibration for input-dependent control flow, and progressive data augmentation to improve cross-architecture prediction accuracy.

  2. TACO
    Kaiyan Chang, Yiming Gan, Wenlong Zhu, and 6 more authors
    ACM Transactions on Architecture and Code Optimization, 2025
    DOI Bib 0

    ScaleGS is an algorithm-architecture co-design system for real-time multi-object 3D Gaussian Splatting in XR rendering. It restructures the rendering pipeline around object-level behavior, separates static and moving objects, exploits parallelism and data reuse across objects and stages, and combines runtime scheduling with hardware acceleration to improve throughput while preserving rendering quality.

  3. SCIS
    Kaiyan Chang*, Mingzhi Chen*, Yunji Chen*, and 40 more authors
    Science China Information Sciences, 2025
    DOI Bib 0

    This paper introduces the Large Processor Chip Model (LPCM), an LLM-driven framework for end-to-end automated computer architecture design. LPCM organizes automation into human-centric, agent-orchestrated, and model-governed levels, uses 3D Gaussian Splatting as a representative workload, and discusses a path from software-hardware co-design toward more autonomous processor-chip design.

  4. TODAES
    Kaiyan Chang, Wenlong Zhu, Kun Wang, and 15 more authors
    ACM Transactions on Design Automation of Electronic Systems, 2025
    DOI Bib 9

    This article presents a data-centric chip design agent framework for Verilog generation. It combines pre-fine-tuning data preparation with post-fine-tuning optimization, using automated Verilog and EDA-script augmentation, RTL-level feedback, iterative filtering, and prompt-guided search to improve LLM-generated RTL quality and PPA-aware design outcomes.

2024

  1. DAC
    Kaiyan Chang, Kun Wang, Nan Yang, and 15 more authors
    In Proceedings of the Design Automation Conference, 2024
    DOI Bib 47

    This paper addresses the scarcity of Verilog and EDA-script training data for LLM-based chip design. It proposes an automated design-data augmentation framework that maps Verilog ASTs, EDA feedback, repair examples, and script descriptions into natural-language-aligned training data, then fine-tunes Llama models to improve Verilog and EDA script generation.

  2. ICCAD
    Kaiyan Chang, Zhirong Chen, Yunhao Zhou, and 8 more authors
    In Proceedings of the IEEE/ACM International Conference on Computer-Aided Design, 2024
    DOI Bib 5

    This paper argues that natural language alone does not provide enough context for many spatially complex hardware architectures. It introduces an open-source benchmark and visual-natural-language query framework for multi-modal Verilog generation, then compares multi-modal models with natural-language-only methods and reports improved generation accuracy when visual design context is included.

2023

  1. Preprint
    Kaiyan Chang, Ying Wang, Haimeng Ren, and 5 more authors
    2023
    DOI Bib 200+

    This work explores whether large language models can generate hardware logic designs from natural-language specifications. It presents ChipGPT, a zero-code logic design framework that prompts an LLM, repairs and optimizes generated Verilog, builds a design space, and searches for implementations under target metrics, showing improved programmability and broader optimization space over native LLM use alone.

  2. NeurIPS Workshop
    Kaiyan Chang, Kun Wang, Mengdi Wang, and 5 more authors
    In NeurIPS 2023 SysML Workshop, 2023
    Bib 0

    PLPilot studies how large language models can support programming-language design. It decomposes language design into LLM-compatible stages, proposes benchmarks for LLM-based programming-language tasks, and evaluates the framework across eight design stages, showing productivity gains over fully manual language design.

  3. NeurIPS Workshop
    Kaiyan Chang, Haimeng Ren, Mengdi Wang, and 5 more authors
    In NeurIPS 2023 SysML Workshop, 2023
    Bib 0

    This work improves LLM-generated hardware by adding post-generation design space exploration. It prompts an LLM to produce initial Verilog, corrects and optimizes candidate programs, organizes them into an HDL search space, and searches for implementations that better satisfy power, performance, and area objectives.

  4. ICCAD
    Yilun Zhao, Yu Chen, He Li, and 5 more authors
    In Proceedings of the IEEE/ACM International Conference on Computer-Aided Design, 2023
    DOI Bib 5

    This paper addresses full-state quantum circuit simulation beyond memory capacity limits. It observes that simply extending memory with secondary storage causes prohibitive data movement, and proposes methods to reduce storage traffic and improve the feasibility of simulating larger quantum circuits on classical systems.

2021

  1. JSA
    Kaiyan Chang, Wei Jiang, Jinyu Zhan, and 2 more authors
    Journal of Systems Architecture, 2021
    DOI Bib 2

    ArchNet targets data hiding for distributed machine learning systems that integrate idle embedded devices into cloud computing. It uses a neural-network-based image encryption scheme supported by a tripartite asymmetric encryption theorem, producing encrypted data that remain usable by deep learning models while being difficult for humans or unauthorized users to recognize.
