Hi! I received my Ph.D. degree in Computer Architecture from the Institute of Computing Technology, Chinese Academy of Sciences in June 2026, advised by Prof. Ying Wang and Prof. Huawei Li. Before that, I entered the undergraduate program in Software Engineering at the University of Electronic Science and Technology of China in 2017 and received my B.Eng. degree in 2021, advised by Prof. Wei Jiang.

My research lies at the intersection of computer architecture, electronic design automation, and large language models. I am particularly interested in building intelligent systems that can understand, generate, verify, and optimize hardware designs. My recent work includes ChipGPT, ChipGPT-FT, multimodal Verilog generation, and LLM-based cost modeling for dataflow accelerators.

Selected publications 代表性论文 All publications 全部论文

  1. Preprint
    Kaiyan Chang, Ying Wang, Haimeng Ren, and 5 more authors
    2023
    DOI Bib 233

    This work explores whether large language models can generate hardware logic designs from natural-language specifications. It presents ChipGPT, a zero-code logic design framework that prompts an LLM, repairs and optimizes generated Verilog, builds a design space, and searches for implementations under target metrics, showing improved programmability and broader optimization space over native LLM use alone.

  2. MICRO
    Kaiyan Chang, Wenlong Zhu, Shengwen Liang, and 2 more authors
    In Proceedings of the IEEE/ACM International Symposium on Microarchitecture, 2025
    DOI Bib 1

    LLMulator is a progressive numeric modeling framework for fast, generalizable performance prediction on dataflow accelerators. It uses LLM program semantics, categorical token modeling for numeric values, reinforcement-learning-based dynamic calibration for input-dependent control flow, and progressive data augmentation to improve cross-architecture prediction accuracy.

  3. DAC
    Kaiyan Chang, Kun Wang, Nan Yang, and 15 more authors
    In Proceedings of the Design Automation Conference, 2024
    DOI Bib 106

    This paper addresses the scarcity of Verilog and EDA-script training data for LLM-based chip design. It proposes an automated design-data augmentation framework that maps Verilog ASTs, EDA feedback, repair examples, and script descriptions into natural-language-aligned training data, then fine-tunes Llama models to improve Verilog and EDA script generation.

  4. TACO
    Kaiyan Chang, Yiming Gan, Wenlong Zhu, and 6 more authors
    ACM Transactions on Architecture and Code Optimization, 2025
    DOI Bib 1

    ScaleGS is an algorithm-architecture co-design system for real-time multi-object 3D Gaussian Splatting in XR rendering. It restructures the rendering pipeline around object-level behavior, separates static and moving objects, exploits parallelism and data reuse across objects and stages, and combines runtime scheduling with hardware acceleration to improve throughput while preserving rendering quality.

  5. ICCAD
    Kaiyan Chang, Zhirong Chen, Yunhao Zhou, and 8 more authors
    In Proceedings of the IEEE/ACM International Conference on Computer-Aided Design, 2024
    DOI Bib 34

    This paper argues that natural language alone does not provide enough context for many spatially complex hardware architectures. It introduces an open-source benchmark and visual-natural-language query framework for multi-modal Verilog generation, then compares multi-modal models with natural-language-only methods and reports improved generation accuracy when visual design context is included.

ChatGPT: A New Option for EDA Design ChatGPT：EDA设计的新选择 China Electronics News 中国电子报 Page 7 第7版 April 21, 2023 2023年4月21日
Quoted remarks 媒体引述 English excerpt 中文摘录 Read quote 查看引文
“Kaiyan Chang, a researcher at the State Key Laboratory of Processors, Institute of Computing Technology, Chinese Academy of Sciences, told China Electronics News that ChatGPT can provide enough reusable code for the chip design industry, offer more innovative code patterns, shorten design time, and improve design efficiency. Because chip design requires a massive amount of code, the industry urgently needs an efficient development tool. Backed by a powerful database, ChatGPT shows strong expressive capability in code generation: with only a task prompt, it can automatically generate corresponding code. In addition, unlike software code patterns, chip design code patterns are relatively fixed, and some code can be generated automatically. Therefore, while traditional automated code generation often provides only fixed code patterns, ChatGPT can provide both fixed code patterns and more innovative ones.”

“In the future, ChatGPT will gradually become a key step in front-end chip design automation workflows, and may evolve into another new paradigm after HLS (high-level synthesis) enabled C-language-based chip design,” Chang said.
“中科院计算所处理器全国重点实验室研究人员常开颜向《中国电子报》记者表示，首先，ChatGPT能够为芯片设计行业提供足够的可复用代码，同时还能提供更多的创新性的代码模式，缩短设计时间，从而提升设计效率。由于芯片行业需要巨大的代码量进行设计，因此急需一个高效的开发工具。背靠强大的数据库，ChatGPT在代码生成方面显示出了优秀的表达能力，只需要给它一个任务提示，就可以自动生成对应的代码。此外，与软件代码模式不同，芯片设计的代码模式相对比较固定，一部分代码可以通过自动化来生成。因此，传统的自动化代码生成模式往往只能提供固定的代码模式，而ChatGPT在提供固定代码模式的同时，还能提供更多的创新性的代码模式。”

“未来，ChatGPT将逐渐演变为芯片前端设计自动化流程中极为关键的一步，在未来很有可能演变成为继HLS（高层次综合）开创C语言设计芯片后的又一种新的范式。”常开颜说。”
